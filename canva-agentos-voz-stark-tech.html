05 / 12

AgentRuntime + AI Router + Tools

La inteligencia esta distribuida: entender, decidir, ejecutar y auditar no son la misma cosa.

AgentRuntime

Mantiene conversacion, memoria de turno, datos faltantes, resumen final y cierre del pedido.

AI Router

Permite usar Gemini, reglas o futuros proveedores bajo un contrato LLMProvider.

Tool Registry

Expone solo acciones permitidas: buscar productos, validar, crear orden, notificar.

Domain Core

Resuelve stock, precios, delivery, impuestos, facturacion y estados sin depender del LLM.

ConversationState

Controla estados como collecting, need_name, need_address, need_payment y closed.

Workflow Engine

Ejecuta pasos, condiciones y tools con traza para explicar que paso y por que.

AgentRuntime + AI Router + LLMProvider + ToolRegistry + WorkflowEngine + Domain Core + ConversationState

06 / 12

Gemini interpreta, no manda

Salida esperada

{ "intent": "order.create", "items": ["1/4 pollo", "gaseosa"], "requested_time": "20:00", "confirms": null, "wants_human": false }

Guardrails

  • temperature = 0 para reducir variabilidad
  • max_output_tokens = 400 para controlar latencia
  • timeout duro de 4 segundos
  • fallback automatico a rule-based NLU
  • detail_answer evita guardar datos incoherentes
Si el producto no existe, no se inventa. Si el stock no alcanza, no confirma. Si faltan datos, pregunta.
